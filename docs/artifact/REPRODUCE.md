# Reproducing the  Results

This artifact regenerates every main/supplement figure and table from committed result
files, with hash verification, and supports an optional live reproduction.

## No-API replay (default)

```bash
npm ci
npm run eval:artifact:check
```

To regenerate only the **result values** (analyses + table `.tex` + `generated_macros.tex`) and run
the evidence gate **without the matplotlib figure step** (Node only, no Python):

```bash
npm run eval:values
```

The numbers are seeded and deterministic, so they regenerate bit-for-bit from the committed result
logs.

To reproduce the **baseline-separation result** (the central RQ4 evidence: no single
conventional-authorization baseline reproduces the full message-bound gate, and a
static-filter + source-message-existence baseline is defeated specifically by the graph-only
sibling-branch family while MBM-Core clears every family):

```bash
node scripts/check_baseline_separation.mjs --md results/baseline-separation-check.md
```

This runs the deterministic gate (no API) for MBM-Core (C5) and the conventional-authorization
baselines over the main suite and asserts the separation properties; it exits non-zero if any
baseline reproduces C5 or if source-exists clears the graph-only family.

`eval:artifact:check` runs, in order:

1. `npm test` — run the deterministic unit/regression suite. One optional AutoGen native-adapter
   test is skipped when the Python `autogen-agentchat` SDK is absent; that skip is expected.
2. `secure:verify` — run the enforced-boundary security battery, review gates, exploit PoCs, and
   audit replay self-test.
3. `eval:context`, `eval:analyze:best-baseline`, `eval:separation`, `policy:comparator`,
   `policy:cedar`, and `eval:e9:analyze:split` — recompute the scoped analyses and comparator checks.
4. `eval:tables` — regenerate `results/latex/tables/*.tex` + generated macro files.
5. `eval:figures` — regenerate all main and supplement figures via
   `tools/build_figures.py` (Python/matplotlib) as SVG + PDF + PNG, and update
   `results/eval/figure_manifest.json` with SHA-256 hashes.
6. `eval:check` — verify figure hashes, paper↔manifest figure coverage, the forbidden-claim
   audit, the anonymization audit, the scoped-claim evidence gates (G1..G10), and the
   result-metadata convention. Exits non-zero on any hard failure.

The evidence report is written to `results/eval/evidence-check.{json,md}`.

## Live reproduction (requires OpenAI access)

Set `OPENAI_API_KEY`. The live runners use the OpenAI Responses API with a strict
`json_schema` decision format (`benchmarks/coupled_memory/live_model.mjs`). Models:
`gpt-5.4-mini`, `gpt-5.4-nano`.

Controlled mechanism effect (E1) and drop-in replacement (E2) are produced by the existing
`coupled:phase6:live:main40-r3:*` and `dropin:bench:live:main40-r3:*` script families in
`package.json`; their combined analyses feed Fig.3 / Table 4 directly.

## Building the paper

```bash
cd paper
pdflatex main && bibtex main && pdflatex main && pdflatex main
# Supplementary material (exact result tables + full S1-S15 figure set):
pdflatex supplementary && bibtex supplementary && pdflatex supplementary && pdflatex supplementary
```

Requires a TeX distribution with `IEEEtran.cls`. Figures are included as PDF; inline numeric
values come from `generated_macros.tex` (regenerated by `eval:tables`), so no number is
hand-typed into the paper. `supplementary.tex` is a standalone `article` document that holds the
result tables omitted from the 10-page manuscript and the complete supplementary figure set.
